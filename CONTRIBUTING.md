# Contributing

Contributions should improve accuracy, reliability, usability, documentation, or tests.

- Explain the problem and expected behavior.
- Add or update tests for behavior changes.
- Keep network behavior bounded and explicit.
- Do not add ranking guarantees or misleading SEO claims.
- Avoid changes whose primary purpose is promotional link placement.
- Keep documentation aligned with what the code actually checks.

Do not submit credentials, private URLs, or sensitive website data in issues or pull requests.
